# The Collector Shelf

A collection deserves better than a shelf it might fall off.

Start with a display case that keeps the dust out and the light in. Group pieces by colour or scale, and leave space between them so each one can be seen.

Lighting changes everything. A soft strip light at the top of the shelf gives figures a clean edge without washing out the paint.
